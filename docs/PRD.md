# 产品需求文档（PRD）

**项目名称：** PostLuma  
**产品定位：** 基于 Cloudflare 的轻量级、多用户临时邮箱系统。

## 1. 产品概述

PostLuma 是一个支持用户注册、管理员审核的私人临时邮箱平台。

用户通过审核后，可以创建多个随机邮箱，用于网站注册、验证码接收等场景。所有邮箱长期保留，用户可以随时查看历史邮件。

系统基于 Cloudflare Workers、Email Routing 和 D1 构建，无需 VPS。

## 2. 核心功能

### 2.1 用户系统
- 初始管理员账号为 `admin`，使用密码登录。
- 用户可自主注册，默认状态为 `pending`。
- 只有管理员审核通过后，用户才能登录进系统，并使用邮箱功能。
- 管理员可以通过、拒绝、封禁用户。
- 用户之间的数据完全隔离。

### 2.2 邮箱管理
- 一键生成随机邮箱地址，自动复制。
- 支持自定义邮箱前缀。
- 支持创建多个邮箱，每个用户拥有独立邮箱列表。
- 支持设置备注、复制地址、搜索邮箱。
- 支持停用和删除邮箱。
- 历史邮箱长期保留，可随时重新查看。

### 2.3 邮件接收
- 支持接收邮件，并且正确渲染。
- 自动识别并突出显示验证码，支持一键复制。
- 提供全局收件箱，集中显示用户所有邮箱的邮件。
- 支持查看单个邮箱的历史邮件。
- 支持邮件搜索、删除和已读状态。

### 2.4 管理后台
- 用户申请审核、封禁与解封。
- 设置用户邮箱数量配额。
- 查看系统使用统计。
- 配置邮件自动清理策略。

## 3. 邮箱状态

| 状态 | 接收新邮件 | 查看历史 |
|---|---|---|
| 正常 | 是 | 是 |
| 已停用 | 否 | 是 |

删除邮箱时可选择是否同时清除历史邮件。

## 4. 页面设计

采用简洁的响应式管理界面。

**用户端**
- 登录 / 注册页面
- 首页：一键创建邮箱、最新邮件、验证码展示
- 邮箱管理：地址列表、备注、状态操作
- 收件箱：全部邮件、按邮箱筛选、邮件详情

**管理员端**
- 用户审核与管理
- 用户邮箱配额设置
- 系统统计与配置

## 5. 技术架构

| 组件 | 技术 |
|---|---|
| 前后端 | Cloudflare Workers + Vue |
| 邮件接收 | Cloudflare Email Routing |
| 邮件处理 | Email Worker |
| 数据存储 | Cloudflare D1 |
| 附件存储 | Cloudflare R2（可选） |
| 用户认证 | 密码哈希 + 安全 Session |
| 安全防护 | Cloudflare Turnstile + 限流 |

**邮件处理流程：**

1. 域名启用 Cloudflare Email Routing Catch-all，指向 Email Worker。
2. Worker 根据收件地址查询 D1。
3. 邮箱存在、处于正常或归档状态，且所属用户已激活 → 接收并保存。
4. 地址不存在、邮箱停用或用户被封禁 → `setReject()` 拒收。
5. 用户登录后只能读取自己邮箱的邮件。

Catch-all 仅用于路由，不代表接受任意邮箱地址。

## 6. 安全要求

- 所有业务接口必须验证用户身份及账户状态。
- 邮箱、邮件查询必须校验资源所有权。
- 密码使用安全哈希算法存储，不保存明文。
- 管理操作仅允许管理员执行。
- 登录与注册接口启用防暴力破解、限流。
- HTML 邮件必须经过安全过滤，禁止执行脚本及默认加载远程跟踪资源。
- 邮件和账户删除应提供明确的数据清理机制。

## 7. 产品目标

以最低部署与维护成本，为少量受信任用户提供一个**简单、安全、可长期管理的临时邮箱平台**。
